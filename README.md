# lexsheet-site

Marketing and landing site for LexSheet, a closing cost calculator that law firms embed on their own websites. Static HTML and CSS deployed to GitHub Pages at https://lexsheet.app, including the privacy policy and terms pages.

## Related repositories

lexsheet-calculator - the embeddable calculator widget served at calc.lexsheet.app

lexsheet-gateway - Cloudflare Worker API for license checks, calculator config, and lead delivery

lexsheet-admin - dashboard for managing firm licenses and lead settings

## Local development

No build step. Open index.html in a browser, or serve the folder with any static file server. Pushes to main deploy automatically through GitHub Pages.
